# Changelog

## Unreleased

### Added

- Initial `etaf-web` application package compiling HTML articles and technical documentation into `etaf-md` intermediate language (`index.md` with YAML front matter, Markdown and `:::` containers) and opening them in `etaf-md`'s reading view.
- Public API: `etaf-web-to-markdown`, `etaf-web-open`, `etaf-web-error`, plus customization options `etaf-web-cache-directory`, `etaf-web-download-images` and `etaf-web-fetch-timeout` (default 30 seconds, with distinct HTTP status, timeout and connection-failure diagnostics).
- Built-in libxml sanitization, main-content extraction (`<article>`, `<main>`, bottom-up Readability prose scoring and structural wrapper tightening), layout-table unwrapping vs data-table preservation, interactive `<form>` and orphan-heading pruning, consecutive `<br><br>` paragraph normalization, bounded HTML `<img>` dimension preservation and tracking-pixel filtering, leading duplicate `<h1>` suppression (including site suffixes and prefixes), `YYYY-MM-DD` date normalization, lazy-load image attribute and widest `srcset` selection, overlong/title-duplicate image alt cleanup, `<figcaption>`-to-image-alt consolidation, makeinfo navigation / permalink (`¶`) / breadcrumb / tail noise pruning, footnote collection, `<details>` and docs callout container compilation, layout-aware mapping for card grids (`:::columns` + `:::card`, stripping decorative card-leading ordinals), docs tabs (`:::tabs`), steps (`:::steps`) and timelines (`:::timeline`), inline sibling spacing normalization, charset detection, on-disk page cache and bounded local image downloading (5 MB per image, 30 images per page).
- Headless rendering for pages whose content a script builds: a document with no prose of its own whose HTML runs a script is rendered through a Chromium-based browser and compiled from that DOM, and a page with no renderer available opens a notice naming the situation and linking the original address.  Public options `etaf-web-render-command` (auto-detect, `off`, or an executable) and `etaf-web-render-timeout` (default 25 seconds).
- Reopening a cached page retries images its first pass could not save, so a failed download no longer leaves placeholders until the cache is cleared.
- Interactive Emacs-native browser shell: inherits the active Emacs theme's frame background with zero chrome background slabs or bottom footer bar; independent `*Web: <host>*` buffers per page; constant-height `1lh` sticky top bar (`:sticky 'top`, pinned and clickable in header-line while scrolling) with clickable `后退 前进 刷新/停止 │ https://host/path   状态`, full scheme always visible, retained-Host pure-text loading progress (`阶段 38% · 2.4s`) on the same row without vertical jitter; per-buffer history stack with scroll restoration (`etaf-web-back`, `etaf-web-forward`), cache-bypassing reload (`etaf-web-reload`), in-flight cancellation (`etaf-web-stop`), plain inline address editing (`etaf-web-focus-address`, zero underline/fill/border change, muted right hint, URL history completion, exiting on both `ESC` and native `C-g`), reliable click and `point + RET` link activation with zero hover highlight, external browser handoff (`etaf-web-open-external`), clean close (`etaf-web-close`), state snapshot (`etaf-web-state`), narrow-viewport folding (`‹ › ⟳` `< 72ch`), and an Emacs-plain error recovery block.
- Non-blocking asynchronous loading pipeline: async HTTP fetching (`curl` via `etaf-process-run` with async `url-retrieve` fallback, using the honest client `User-Agent` `etaf-web/0.1 (Emacs; +https://etaf.top)` rather than a spoofed browser string so CDN/Cloudflare endpoints such as `w3.org` serve public pages without TLS-fingerprint HTTP 403 rejections), async headless Chromium rendering (`--blink-settings=imagesEnabled=false` + shared disk cache), text-first display with concurrent background image backfill, and retained-Host progress updates without full-page rerenders.
- Universal HTML layout/extraction compiler improvements (compiler version 17): compiling HTML5 MathML `<math>` equations (`<annotation encoding="application/x-tex">` and `alttext`) into native `$...$` / `$$...$$` LaTeX without duplicating MathML text; stripping MediaWiki `.mw-editsection` chrome so Wikipedia/Arch Wiki section headings survive cleanly; preserving discussion comment trees on dedicated thread pages (such as Hacker News items) when no primary article exists; spacing adjacent inline block/`<button>`/`<kbd>` boundaries (fixing Rustdoc and Tailwind hero links); recognizing JavaScript-required stub notices as thin shells for automatic Tier 3 escalation; matching Docs sidebar classes per class token (Nextra, Tailwind docs) while excluding search-classifier metadata sidebars (PyPI); keeping single-line `etaf-web--plain-input-view` wrappers structurally stable during typing so toggling the inline clear button never drops input focus; hardening Tier 3 CDP distillation for CSS custom `opacity: 0` checkboxes, sibling `<label>` deduplication, app-shell sibling header/footer preservation, and post-submit live input value sync; treating any HTML5 block-level anchor or custom element containing block descendants (such as `<a class="card">` and GitHub's `<markdown-accessiblity-table>`) as a block container so linked cards never collapse into inline soup and wrapped tables stay GFM pipe tables; preserving `<ul>`/`<ol>` link lists inside primary `<article>`/`<main>` landmarks; unwrapping headerless sparse/spacer-row layout tables (e.g. Hacker News) using plain-text cell width; collecting MediaWiki `cite_note` footnote definitions; extracting card titles through intermediate `<div>`/`<section>` wrappers; deduplicating a leading `<h1>` preceded only by a short hero eyebrow/kicker; using visible text boundaries for CJK/Latin inline spacing and separating adjacent `<a><small|time|cite>` elements; supporting a leading section heading and CJK short titles in homogeneous entry streams without repeating the entry link; generalizing Docs sidebar detection and nested tree extraction across structural `<aside>`/`<nav>` trees, VitePress `<section>`/multi-link `<li>` groups and MkDocs `<nav>`-wrapped sublists; parsing embedded Docs and Discourse Markdown with the `'etaf` dialect so `:::` callouts, tabs, details and cards render natively inside split views; adding `scripts/corpus.py` (`corpus-check`, `corpus-diff`, `corpus-audit`, `corpus-benchmark`) for automated multi-archetype benchmarking and non-regressing golden-corpus verification; excluding embedded `<article>` cards inside `<aside>`/embed/preview/comment containers and enforcing real content coverage during main-content extraction so link-preview oneboxes never truncate long pages; isolated fragment compilation mode preserving `<aside class="quote">` / `<aside class="onebox">` blocks and inline emoji labels; universal lightbox `<a><img></a>` unwrapping to standalone block images; progressive async image downloading and direct cache-asset resolution in embedded Markdown views (Discourse threads and Docs pages); post-hydration classification routing JS-hydrated blogs/docs/articles to cached Tier 1/2 reading views while keeping true interactive SPAs in Tier 3 Live CDP; conditional `<noscript>` server-rendered fallback when the main body is a script shell (sanitizing all fallback nodes and rejecting short JavaScript-required notices); pruning screen-reader-only chrome (`.sr-only`, `.visually-hidden`, `.sl-anchor-link`), inline hidden nodes (preserving `role="tabpanel"`), ARIA overlays (`tooltip`/`menu`/`dialog`/`alertdialog`), short non-`<form>` search bars and lone punctuation/pipe leaf blocks; preserving line breaks inside block-per-line `<pre><code>` containers (such as Starlight Expressive Code `.ec-line` divs); unwrapping chapter-level `<details open>` sections into normal headings and blank-line-separated blocks (preserving closed and short `<details>`);   + prose summary + metadata line + `---`; dropping empty-alt inline images, degrading badge image runs to `alt` text, and stripping PUA / variation selectors while preserving standard emoji.
- Tiered rendering foundation: uniform Page Controller abstraction decoupling the browser body viewport from `etaf-md`, Stage 0/Stage 1 deterministic routing, Tier 2 adapter registry (`etaf-web-register-adapter`, `etaf-web-unregister-adapter`, `etaf-web-adapters`), per-host mode switching (`etaf-web-set-mode` bound to `m`, persisted in `site-prefs.json`), `etaf-web-external-browser-function` handoff option, `:tier`/`:mode`/`:adapter` fields in `etaf-web-state`, and headless Chromium render fix removing `--virtual-time-budget=3000` (which stalled on long-polling sites) with clear timeout/failure diagnostics.

  - Dual-theme semantic state tokens in `etaf-web` (`:web-sidebar-bg`, `:web-hover-bg`, `:web-selected-bg`, `:web-op-bg`, `:web-border-soft`, `:web-dot-purple`, `:web-dot-teal`) with hex normalization of Emacs named colors and live refresh when Emacs themes change.
  - Universal Docs engine adapter (`docs`): detects Starlight, VitePress, Docusaurus, MkDocs, Sphinx, mdBook, GitBook, VuePress, Antora, Fumadocs, Nextra and Texinfo docs sites, rendering full-height independently scrollable split panes with a same-canvas chapter sidebar (`sidebar` collapse icon, ordinary single-line filter input with leading `search` icon `/`, inset 1-line active-chapter strip with accent bar, borderless locale footer), draggable `etaf-pane-resizer` divider (`[`/`]` keyboard resize), symmetrically centered embedded `etaf-ui-markdown` reading column (`-`/`+` width adjustment), inline `≡ 目录` breadcrumb trigger with left `etaf-drawer` (`s`) when collapsed or narrow, and `H`/`L` prev/next chapter navigation.
- Tier 3 Live CDP interactive projection (`etaf-web-cdp`, `etaf-web-live`, `backends/cdp-bridge/`): zero-dependency Node.js 22+ NDJSON bridge managing a single shared Headless Chromium with persistent profile and idle shutdown, in-page semantic/layout distiller + `MutationObserver` sync, interactive ETAF/`etaf-ui` projection (`topbar`, `sidebar`/`drawer`, `main`, `modal`, buttons, inputs with stable mid-edit focus and collision-free refs across DOM updates, `opacity: 0` custom checkboxes with sibling labels, app-shell sibling preservation, selects, tabs, tables), automatic escalation for JS-only SPA shells, T4 canvas/challenge handoff notice, and public `etaf-web-cdp-available-p`, `etaf-web-cdp-shutdown`, `etaf-web-live-enabled` and `etaf-web-node-program`.
- Multi-architecture rendering hardening (compiler v18) & 79-site automated benchmark (`scripts/corpus.py`): HTML5 MathML-to-LaTeX extraction (`$...$` / `$$...$$`), MediaWiki `.mw-editsection` stripping and `<ol class="references">` deduplication with emptied-heading cleanup, HTML `<select>`/`<option>` form stripping, word-bounded `share` boilerplate matching (preserving CSS-Modules `shared__*`), `<main>` and landmark-less discussion comment-tree preservation, CJK-weighted Readability with multi-sibling / OP-heading ascent and multi-`<article>` editorial feed selection, `colspan`-aware sparse layout-table unwrapping, block-anchor `<article><h2>` link preservation with long-prose cap, adjacent `<button>`/`<kbd>`/link inline spacing, header/footer exclusion and docs-signal gating in `docs` adapter (eliminating false positives on news/media/community sites), HTTP `Accept: text/html` content negotiation, clear HTTP 403/405 challenge diagnostics, Tier 3 single-line inline-row geometry + React controlled `<select>` setter, and full normalization of `:::details`, `:::card`/`:::columns`, `:::tabs`, `:::steps`, `:::timeline`, and callout containers inside embedded Tier 2 panes.
- Four-layer code block language identification (`etaf-web-lang`, compiler v19): extracts language metadata from `<code>`, `<pre>`, 1..3 ancestor wrappers (Sphinx, Pygments, GitHub, VitePress, Docusaurus, MkDocs, Rustdoc, PyPI), sibling language badges and filename captions; normalizes lexer aliases while honoring explicit plain-text / ASCII-art locks; applies deterministic high-precision content anchors (shebang, JSON parse, diff, HTTP wire message, Python REPL, Dockerfile, Makefile, Elisp/Lisp S-expressions, HTML/JSX/XML, SQL, Bash/shell sessions, TOML/INI); and uses a margin-gated weighted feature scorer with a weak page-level prior to boost real code recognition from 22.0% to 89.8% across the 79-site / 836-block corpus without misclassifying prose, keybindings or ASCII diagrams.
- Visible cursor and native Emacs cursor operations in rendered web pages: keeps the Emacs cursor permanently visible across pointer events (`etaf-cursor-follows-input-modality nil`), lands initial point inside the page body rather than the row-1 toolbar, provides smooth character/line/page cursor motion (`C-f`/`C-b`/`C-n`/`C-p`/arrow keys, smart `C-a`/`C-e`, `M-<`/`M->`/`Home`/`End`, active-pane `C-v`/`M-v`) with automatic viewport scrolling at pane edges and preserved column, enables native Emacs mark/region, Shift-selection, mouse drag selection (`:text-selection t`) and clean property-free / margin-dedented `M-w` copy, adds `w` to copy link or page URLs, and keeps `RET` safe on non-link text.
