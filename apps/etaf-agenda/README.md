# etaf-agenda

一个基于 [ETAF](https://github.com/emacs-taf/etaf) 的个人日程与任务应用。今日、日历、清单、项目、习惯、回顾六页共用同一套数据模型：所有记录存放在本地 SQLite 数据库，全部配色动态派生自当前 Emacs 主题，不硬编码第二套调色板、不修改字号、完整保留 Emacs 原生模式行。

## 要求

- Emacs 29.1 或更新版本。
- 提供者检出：`etaf`、`etaf-ui`、`ebox`、`ecss`、`ekp`、`etaf-db`（位于本单仓的 `packages/` 下或同级目录）。

## 安装与运行

把本包根目录与提供者根目录加入 `load-path` 后：

```elisp
(require 'etaf-agenda)
M-x etaf-agenda-open
```

数据库默认位于 `~/.emacs.d/etaf-agenda/agenda.sqlite3`，首次打开自动初始化并在旧版本 schema 上按序迁移；`etaf-agenda-open` 也可直接传入自定义数据库路径。支持在运行时直接 `load-theme` 切换深浅主题，所有表面、语义色与 `etaf-ui` 控件原地重绘。

完整公开接口清单见入口文件 [etaf-agenda.el](etaf-agenda.el) 的 Commentary。

## 六页一览

| 页 | 内容 |
| --- | --- |
| 今日 | 逾期、日程、待办、记录与问题、已迁移五区；右栏提供一键习惯打卡、本周节奏与月度热力图 |
| 日历 | 年视图（12 月悬浮概览 + 热力图例）、月视图（7 列自适应网格）与 7 日周视图切换（`w`），四面零抖动高亮选框，右栏同时列出选中日的日程与待办 |
| 清单 | 按时间、领域、项目或状态分组（`g`），支持显示/隐藏已完成（`H`） |
| 项目 | 真实完成进度条、阶段划分、阶段内快速新建与右栏阶段进度概览 |
| 习惯 | 近 21 天（窄屏 14 天）1:1 正方格打卡矩阵，支持点击任意日期或 `h` / `l` 补卡 |
| 回顾 | 四列月度 KPI、按领域/按项目条形分布、四阶 1:1 正方格热力图、高频迁移警示与效率洞察 |

## 响应式视口与最小尺寸

界面按宽屏 / 中屏 / 窄屏三档与矮屏自动适配，并在窗口变化时实时重排：

- **宽屏（≥ 126 列）**：左侧导航栏（可拖动分隔线调整宽度）+ 中央工作区 + 右侧上下文/详情检查器三栏布局。
- **中屏（88–125 列）**：自动折叠左栏，顶栏出现视角切换入口，保留中央工作区与右栏两栏布局。
- **窄屏（< 88 列）**：顶栏自动折为两行紧凑布局，主区单栏展示；按 `RET` 时详情检查器接管画布，`Esc` 返回。
- **矮屏（≤ 25 行）**：顶栏收紧至 1 行，主区与侧栏保持内部独立滚动。
- **最小可用视口**：72 × 20；更小尺寸下保持结构不崩溃并通过内部滚动访问全部内容。

## 键盘与鼠标交互

遵循 ETAF 统一键盘导航协议，保留 `Tab`、`Shift-Tab`、`M-g`、方向键、`Esc` 与 `?` 等框架通用键：

| 键 | 作用 |
| --- | --- |
| `1` … `6` | 切换今日 / 日历 / 清单 / 项目 / 习惯 / 回顾页 |
| `M-g` | 区域跳转（`f` 顶栏搜索、`s` 左栏、`m` 主工作区、`r` 右栏详情） |
| `j` / `k` 或 `↑` / `↓` | 在当前页条目之间上下移动 |
| `h` / `l` / `t` | 前一天 / 后一天 / 回到今天（习惯页移动补卡光标日） |
| `[` / `]` | 上一年 / 下一年、上个月 / 下个月或上一周 / 下一周 |
| `w` | 在日历页循环切换年视图 / 月视图 / 周视图 |
| `a` / `c` | 原位新建条目 / minibuffer 快捷捕捉 |
| `e` | 原位编辑选中条目标题 |
| `RET` | 打开右侧可编辑详情检查器（焦点在控件上时激活控件） |
| `x` | 完成 / 撤销完成（支持逾期、循环任务自动生下次、习惯打卡） |
| `m` / `M` | 智能迁移（逾期→今天 / 当日→明天 / 已迁移→迁回）/ 批量延逾期至今日 |
| `s` / `!` / `S` | 切换状态 / 切换优先级 / 调整计划日期 |
| `z` / `d` / `u` | 放弃 / 软删除 / 撤销上次操作 |
| `/` / `f` | 实时搜索（标题、标签、备注、领域、项目）/ 筛选领域或切换项目 |
| `g` / `H` | 切换清单分组 / 显示或隐藏已完成 |
| `A` / `P` | 新建领域（项目页为新建阶段）/ 新建项目 |
| `Esc` | 分层退出（原位编辑 → 新建行 → 搜索 → 详情检查器 → 取消选中） |
| `?` | 打开 ETAF 原生快捷键帮助面板 |

自然语言捕捉示例：`明天 15:00-16:00 评审设计 !1 #UI @工作 +网站改版 ~45m 截止:周五 重复:每周`，另支持 `每天 晨跑`（习惯）、`- 记录`、`? 问题`。
