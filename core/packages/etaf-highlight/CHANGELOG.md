# Changelog

All notable changes to `etaf-highlight` are documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.1] - 2026-11-26

### Changed

- Updated README, manual and empty-state popup guidance to lead with public `M-x` commands and explicitly document `etaf-ext`'s configurable dispatcher prefix and user key customization instead of hardcoded key chords.

## [0.1.0] - 2026-11-26

### Added

- Standalone universal highlighter and persistent companion note card extension (`etaf-highlight-add`, `etaf-highlight-apply`, `etaf-highlight-remove`, `etaf-highlight-list`, `etaf-highlight-entries`) built over `etaf-ext` public APIs.
