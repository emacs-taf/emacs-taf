# Changelog

All notable changes to `etaf-doc` are documented in this file.

## [0.1.0] - 2026-11-28

### Added

- Extracted Markdown parser, syntax highlighter and block view renderer out of `etaf-ui` into `etaf-doc`.
- Unified bounded disk cache, remote image fetching, QR rendering, embedded QuickJS Mermaid/MathJax typesetting, local asset helpers, node protocol and common editorial block widgets shared by `etaf-md` and `etaf-org`.
